安心更新，留住回忆

  1. 已有旧版？先在设置中导出完整备份。
  2. 下载后打开 APK，按系统提示允许本次使用的浏览器安装应用。
  3. 直接覆盖安装，保留原有记录。请勿先卸载旧版。

若微信内无法下载，请选择“在浏览器打开”。遇到签名冲突，请保留旧版并联系开发者。

个人纪念日、照片与分类保存在手机中；双人打卡及主动选择的共享内容同步至腾讯 CloudBase。此下载页面不收集纪念日数据。
