## 安装与剩余限制

先导出纪念日备份，直接覆盖安装，不要卸载旧版。旧账号以原用户名和密码登录，在“打卡 → 右上角账号与伙伴 → 账号安全与邮箱”绑定邮箱；不要重新注册替代旧身份。朋友通过“邀请朋友注册”的链接开通，注册不会自动配对。

构建：JBR 21、Gradle 8.13、AGP 8.13.2、Kotlin 2.0.21、Compose BOM 2024.12.01，SDK platform36/buildtools35。模拟器使用软件渲染避开本机 Vulkan 驱动问题。Android Studio 打开工程 ZIP 内 WithYouAnniversary 目录；机器专属 local.properties、签名私钥、缓存和凭据不包含在源码包中。其他电脑的默认 debug 签名通常不能覆盖现有安装。

未验证实体手机、各厂商 ROM、全部收件服务、长期投递信誉/负载、整月免费额度和极端竞争时序。图形验证码触发时安全失败并提示稍后重试/联系管理员，未嵌入完整图片验证 UI。密码恢复后的业务访问截止不等于 CloudBase 原生用户信息 JWT 立刻失效；离线缓存/截图不能远程擦除。原有前台同步、体验期限与额度、对方共享纪念日不能绑定桌面小组件、账号 JSON 导出无一键导入等限制保留。
