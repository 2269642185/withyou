# 1.8.2 打卡时间与完成收纳验证

2026-10-21。发布前快照，实际公开状态另见 v1.8.2-publication.md。

## 实现

打卡默认显示简略时间，点击原位置展开完整年月日与秒，再点收起，不显示时区文字。个人/伙伴/共同事项的卡片与记录使用同一时间格式。记录改为自适应内容高度的底部面板，单条记录不会撑成大弹窗；昵称、表情、完成状态、时间分层排列，日期分组，长备注折叠，长列表滚动，关闭按钮固定在顶部。全 App 主源码 UI 不再出现“上海”说明，内部既有时区与日期规则未变。

完成一次性待办后当天保留主列表，到下一个日历日移入底部默认折叠“已完成”；缩小记录可看时间、查看历史及撤销/编辑/删除本人事项。只改变展示，不写归档或删除、不改变权限/统计/队列。未知完成日期的旧事项保留主列表，不猜测收纳日期。习惯和共同事项按每日计划继续显示，昨日记录留在历史；共同事项本人和伙伴分别记录，不把一方完成当双方完成。

时间切换与列表变化使用短过渡，遵循温柔动画与系统关闭动画设置；冷启动直接按日期显示，收纳区默认折叠，避免大量旧卡片逐张入场。标准底部面板仍使用系统原生过渡。

新增可空 completed_at（UTC Instant），点击时保存、队列原样上传，不用同步时间替代。取消清空完成时间，再完成记录新时间；没有新增完整操作审计表。旧记录不补造精确时间，显示“具体时间未记录”。手机时钟是记录来源，无法据此证明设备时钟未被修改。
