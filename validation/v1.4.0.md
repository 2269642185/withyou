## 明确限制

- 没有连接用户真机；真机网络、厂商安全扫描、未知来源设置及安装提示尚未验证。
- 最低 API 26 通过静态兼容检查；实际仪器测试运行于 Android 16 / API 36，未逐一运行 Android 8–15。
- GitHub 在部分网络下不可访问，页面上线不等于所有国内手机网络均能访问；失败不会影响本地纪念日使用。

- 安装由 Android 系统确认，可能有 Play Protect 或厂商扫描；不静默安装、不绕过系统保护。
- 不支持断点续传；下载中进程被系统终止需要重新下载。完整下载会在重开后重新校验。
- 桌面跨日刷新仍受系统后台及省电策略影响。
