## 使用与限制

手机“设置 → 版本与更新 → 检查更新”，或从下载页取得 APK 直接覆盖，勿卸载。主题选择位于“设置 → 主题配色”；账号入口统一在“设置 → 账号与伙伴”。未配对用 B 心动日历；确认配对后，App 退到后台时刷新为 C 双人轨道，避免切换当前入口使页面退出。确认解除或主动退出登录恢复 B；网络错误及凭据过期不触发图标解除。

部分桌面会缓存旧图标，旧版固定 MainActivity 快捷方式可能继续显示个人图标。可仅移除桌面快捷方式，从应用列表重加，不卸载 App。未验证各厂商桌面、Android 8–15 运行时或实体手机；不保证立即刷新或保持原快捷方式位置。未重跑系统在线安装器全流程，已验证匿名更新发现/下载及准确 APK 的模拟器覆盖。

登录前的本机打卡与账号记录单独保留，不自动合并上传；退出登录可回本机记录。打卡 JSON 暂无一键导入，纪念日 ZIP 备份不含打卡。云端免费体验期限、额度及无每日邮件总量硬上限等既有限制保留。
