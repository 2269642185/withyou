## 明确边界

- 仅有 API 36 模拟器与真实云端测试，没有连接用户的两部物理手机；厂商安装扫描、网络、后台行为需实际联调。
- Android 8–15 仅进行静态兼容检查，未逐版本设备测试。
- 前台低频同步，失败退避，不是即时后台推送；无通知提醒。
- 习惯跨日后不会自动补签，旧配对队列会停止传送并展示草稿摘要。共同事项类型创建后固定，解除后的旧共同事项只能查阅、归档或删除，不自动转给新伙伴。
- 第一版为双人受邀注册，云端注册激活码由管理员生成，不是无限公开注册。忘记密码通过管理员处理，未做自助找回。
- 打卡 JSON 导出尚无一键导入；纪念日原 ZIP 备份恢复继续支持。管理员业务备份不包含平台账号认证库，不是完整云环境恢复镜像。
- 客户端按账号最多 500 个未删除事项；单次云端响应限制 8 MiB，大量多年历史需要后续分页优化。未做大规模负载、长时间压力或月度额度实测。
- 沿用原 debug 签名以覆盖已有安装，未宣称应用商店发布就绪。签名私钥不会打包或上传。
- 共享数据按云端权限访问，不是端到端加密；设备离线期间无法即时获知解除配对，已看过或导出的内容不能撤回。
