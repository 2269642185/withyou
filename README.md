# 与你 · 纪念日 1.8.1

中文 Android 原生应用，Kotlin + Jetpack Compose / Material 3，奶油治愈风。

## 1.8.1 同步恢复与安全诊断

针对用户反馈的“云端请求未完成（400）”修复客户端的已确认薄弱环节，不把未拿到详情的原手机错误归因于登录过期。新增跨 Activity/ViewModel 的进程级续期锁，使用磁盘上最新的加密凭据，避免重复使用已轮换的 refresh_token；续期完成后以条件替换保存，不能恢复已退出的登录，也不能覆盖另一个账号。

普通业务 400、网络中断、401 和刷新接口明确拒绝分别处理。同步遇到 401 时只尝试一次续期，重发沿用原操作编号；确认登录失效后保留当前账号的本机记录与队列，停止自动重试，打卡页显示“重新登录”。原有 SESSION_REVOKED 安全清理与云端权限保持不变。

新增“同步详情”，只复制版本、环节、HTTP 状态、允许的错误码、请求编号和队列数量，不含原始响应、账号、事项内容、照片、密码或令牌。没有修改 CloudBase 配置、SQL 或 SMTP，也不实现仍在设计预览中的自选表情。完整验证见 validation/v1.8.1.md。

## 1.8.0 个人日常、双人陪伴与主题配色

默认启动纪念日。未登录也可创建、编辑、归档、删除和完成个人打卡；无需为了本地使用注册账号。未配对时隐藏“我们的共享”、纪念日分享按钮、伙伴进度、归属标签及共同事项创建选项。账号入口统一位于“设置 → 账号与伙伴”；只有确认配对后才出现双人界面。原私密事项不会自动共享；配对后的新事项延续现有默认共享设置。

设置中的“主题配色”提供奶油杏、薄荷绿、樱花粉、雾霾蓝、薰衣草紫、燕麦棕，分别支持浅色、深色和跟随系统。选择即时生效并保存，不改写纪念日自定义背景、照片、字体及桌面小组件配色，不同步对方的本机主题偏好。

桌面启动图标：个人使用 B 心动日历，确认配对后 C 双人轨道，确认解除后恢复 B。已确认配对的离线副本、网络失败或登录凭据失效不会直接改变图标；主动退出登录切回 B。配对状态先保存，App 退到后台时再刷新图标，避免关闭当前入口导致页面退出。图标别名切换按 Android 官方 PackageManager 接口实现，API 33 及以上批量更新，旧系统先开启目标入口，再关闭旧入口；MainActivity 保持可用，避免破坏小组件和注册链接。不同厂商桌面的刷新和旧快捷方式处理仍需真机验证。

登录前的本机打卡与各登录账号独立保存，不自动合并、上传或迁移；退出登录可回到本机记录。“设置 → 账号与伙伴”可导出本机打卡 JSON；账号登录后导出当前账号数据。JSON 暂无一键导入，纪念日完整 ZIP 备份仍仅覆盖纪念日、照片及外观设置，不包含打卡。解除配对后旧共同事项退出日常列表，但本人数据保留在账号文件与 JSON 导出中。

升级无需卸载。同签名验证与覆盖保留结果见 validation/v1.8.0.md，公开发布结果另见 validation/v1.8.0-publication.md。Android Studio 打开工程根目录，使用 Android Studio JBR 21、Gradle 8.13、AGP 8.13.2、Kotlin 2.0.21、SDK 36；未更换依赖或签名。

## 1.7.0 邮箱注册与账号恢复

新增邮箱验证码注册、邮箱或原用户名密码登录、忘记密码，以及原账号绑定/修改邮箱。旧账号不重新创建、不合并身份，纪念日、待办、配对和照片继续沿用。个人纪念日仍可免登录使用。

逐步开放给朋友：已有用户在“打卡 → 右上角账号与伙伴 → 邀请朋友注册”复制链接；链接 72 小时有效、一次使用。对方安装最新版后打开链接或在注册页粘贴，验证邮箱后开通。注册资格与双人配对独立，双方确认配对后才共享。服务端默认最多 200 个已开通账号，单个用户每日最多生成 5 个注册链接；这不是邮件发送总额限制。

发信使用用户指定的 QQ 邮箱 SMTP，凭据仅保存在 CloudBase。邮件正文包含应用名称、验证码、有效期及非本人操作提示。采用平台频率限制、异常验证及管理员关闭开关；用户已接受第一版不提供全局每日邮件硬上限，不擅自购买服务或升级套餐。

找回密码后调用官方会话撤销，并设置应用业务数据的服务端会话截止时间。旧访问令牌停止读取业务数据和私有云照片，新版客户端清除失效会话并保留本机待同步记录，重新登录仍为原 UID。CloudBase 原生用户信息接口的旧 JWT 可能持续到到期，不能把业务校验描述为整个身份平台令牌立刻失效；离线副本也不能远程擦除。

环境迁移和运维见 cloudbase/email/README.md；发布前验证见 validation/v1.7.0.md。本版沿用原签名，可覆盖安装；通过验证后按既有授权发布 GitHub Release 与下载页。

## 1.1 功能

- **30 种背景色**：奶油、花瓣、自然、天空、暮色五组，保留原来五种颜色编号。
- **简单配色**：自动、深色、浅色及精选文字色；自动文字适配明暗背景。

- **温柔动画**：页面轻移淡入、卡片按压、列表置顶排序、配色和天数淡变；周年当天播放一次少量花瓣。支持应用开关，监听系统动画开关；周年播放标记按记录与本地日期保存在本机。
- **自定义分类**：创建、重命名、图标、颜色、删除确认、首页筛选和数量；编辑纪念日时也能创建分类。删除分类保留纪念日，转为未分类。最多 50 个分类，名称 1–20 字且不重复。

## 日期与保存

默认开始当天为第 1 天，也可选择实际间隔；未来日期均按实际日历间隔倒计时。当天显示“就是今天”。累计天数与周年倒计时分别计算，周年当天倒计时为 0。

按手机当前时区的 LocalDate 计算，跨日、返回前台、日期或时区变化时刷新。2 月 29 日在非闰年的周年日为 2 月 28 日，闰年恢复 2 月 29 日。未来事件的下一纪念日期不会早于起始日。

记录、分类、配色和设置使用单个 AtomicFile JSON 快照；进程共享锁防止小组件读取与页面保存竞争。数据格式为 v3，可读取 v1/v2 本地数据和旧备份；已有记录默认未分类。保存成功后才更新界面。

照片复制到私有目录，应用 EXIF 方向并压缩为静态 JPEG，最长边至多 1800 像素，源图限制 30 MB。外部原图移除后不影响已导入的副本。透明和动画不保留；未引用的旧照片在一天宽限后于后续保存时清理。

## 备份恢复

设置中导出 ZIP，包含记录、分类、全部记录配色、主题/默认规则/动画设置和引用中的照片。恢复前确认、完整校验，再整体替换，不合并。兼容 v1/v2 ZIP；失效分类归入未分类。最多 500 条纪念日，解包总量上限 150 MB。

桌面实例的位置由桌面管理，实例绑定与独立配色保存在本机，不随 ZIP 转移。恢复记录时不会自动改绑现有组件；引用不存在时显示重新选择。新手机或重新安装后需重新添加和配置组件。

备份未加密，含个人信息，请保存在可信位置。卸载会清除私有数据；系统云备份和应用设备迁移关闭。升级安装同一签名 APK 会保留数据。
