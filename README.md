## 1.6.0 彼此看见日常，也共享纪念

打卡改为统一列表，以“我 · 昵称 / 伙伴 · 昵称 / 共同事项”标签区分归属。已配对时新事项默认共享，旧的私密事项保持不变；隐私开关放在折叠设置。当天双方进度按实际计划计算，过往已完成的一次性待办不重复计入，休息日不计入，共同事项分别记录双方完成。加入按压、卡片完成色、进度和一次性共同完成庆祝动效，服从应用和系统动画开关。

纪念日详情可主动分享，也可从首页“我们的共享”选择一份纪念。共享完整六款模板、日期、计数方式、背景与字体颜色、遮罩以及照片；共享日期统一按上海日历计算，原本私密纪念日仍用本地日期。照片经过重新编码，保存在私有 CloudBase PostgreSQL Storage，通过登录令牌和当前配对权限读取，不使用永久公开链接。共享修改和照片先保存到本机队列，成功上传照片后才提交对应外观版本；未上传完成会明确显示待同步。本人编辑自己在当前配对下已共享的记录时会排队更新，其他设备创建的共享记录仅查看，不自动覆盖本机私密记录。

停止共享、删除已共享记录、解除配对通过服务器权限撤销；另一端在前台联网同步后清理照片缓存。离线副本要等重新联网才能获知撤回；截图或已导出内容无法撤回。原有个人纪念日照片、分类、小组件和 ZIP 备份保持本地保存，不会批量上传。共享纪念日第一版在 App 内查看，尚不能绑定对方的共享记录为桌面小组件。

## 打开与构建

Android Studio → Open → 选择本工程根目录。Gradle JDK 选择 Embedded JDK。本机 SDK 已在 local.properties 配置；工程压缩包不带机器专属路径，在其他电脑打开时由 Studio 生成。

| 环境 | 实际使用 |
|---|---|
| Android Studio | 2025.2.2，D:\software\Android Studio |
| JDK | Studio JBR 21.0.8；未使用 PATH 中的 Java 11 |
| SDK / Build Tools | D:\Android\SDK，platform 36 / 35.0.0 |
| Gradle / AGP | Wrapper 8.13 / 8.13.2 |
| Kotlin / Compose | 2.0.21 / BOM 2024.12.01 |
| Android | 最低 API 26（Android 8.0），target / compile 36 |

其他电脑需要 JDK 17 或 21、本机 SDK 和首次联网下载依赖。EXIF 依赖原样附带于 app/libs，保留官方校验、来源与许可证说明，用于避开本机观察到的 Java TLS 下载中断。

## 1.3.0 桌面同步卡片外观

- 小组件默认“跟随卡片外观”，同步对应记录的照片、背景色、文字色、遮罩和简化模板；编辑并保存或恢复备份后刷新所有受影响实例。原“跟随纪念日配色”的开关沿用同一存储键，不重置已有设置。
- 全幅照片与带照片的奶油经典使用裁切照片和渐变遮罩。拍立得小尺寸优先天数，简化为全幅照片；中尺寸左右分区、大尺寸上下分区，文字位于纸面。
- 极简采用居中数字；票根使用缺口与虚线；便笺使用纸面横线与胶带装饰。纸面模板不会显示仅保留在记录里的照片。
- 独立配色继续使用独立纯色与简洁布局，不随记录照片/模板/配色改变；原有绑定与颜色均保留。切换回跟随立即采用当前卡片。
- 配置页提供小、中、大实际 RemoteViews 预览及简化说明。尺寸由桌面给出的 dp 尺寸决定，不保证所有桌面网格完全相同。
- 背景照片按尺寸中心裁切，单张背景最多 72,000 像素，源照片最长边采样到 512 像素以内，采用有界缓存；文字为独立原生 TextView，保留辅助功能、自动缩放和点击。缺失/损坏照片使用默认风景。
- 广播与前台刷新在后台线程执行；跨日、日期/时区变化、调整尺寸、重启后重新读取数据。系统省电、强停可能延迟刷新，仍不承诺精确午夜更新。

## 1.2.0 六款卡片模板

- 奶油经典：沿用原有柔和卡片；拍立得：照片上置、纸面说明；全幅照片：照片满铺、渐变遮罩；极简数字：居中大数字；纪念票根：票根分区、虚线和装饰条码；手写便笺：纸面横线与胶带装饰，正文使用系统可读字体。
- 新增/编辑页点击“卡片模板”，在双列预览面板选择，当前标题、日期、天数和配色实时用于预览。完成只关闭面板，点击“保存纪念日”才写入记录；取消编辑保留原记录。
- 每条记录独立保存模板，首页置顶、列表与详情共同使用；切换模板保留照片和全部配色。照片不适用的布局保留文件但不显示照片，切回照片布局可继续使用。
- 照片模板无照片或照片缺失时使用内置风景背景，允许无照片保存；编辑页提供添加照片入口。全幅照片采用渐变遮罩，拍立得文字位于照片外的纸面。
- 模板在备份中保存，兼容 v1/v2 旧数据；缺少或未知模板使用奶油经典。数据格式 v3。
- 1.2 版本当时未同步小组件；1.3 已加入上述同步功能。切换模板淡入过渡遵循动画开关，列表滚动不重复播放入场动画。

## 1.1 功能

- **30 种背景色**：奶油、花瓣、自然、天空、暮色五组，保留原来五种颜色编号。
- **简单配色**：自动、深色、浅色及精选文字色；自动文字适配明暗背景。
- **高级配色**：自定义背景、统一文字、标题、天数、辅助文字 HEX，照片遮罩强度、恢复默认及对比度提示。编辑页提供实时卡片预览。
- **温柔动画**：页面轻移淡入、卡片按压、列表置顶排序、配色和天数淡变；周年当天播放一次少量花瓣。支持应用开关，监听系统动画开关；周年播放标记按记录与本地日期保存在本机。
- **自定义分类**：创建、重命名、图标、颜色、删除确认、首页筛选和数量；编辑纪念日时也能创建分类。删除分类保留纪念日，转为未分类。最多 50 个分类，名称 1–20 字且不重复。
- **多尺寸桌面组件**：小、中、大三个入口，目标为 2×2、4×2、4×4，均支持调整尺寸和响应式布局；格子和实际尺寸取决于桌面。
- **独立小组件**：每个实例独立选择纪念日、跟随记录配色或使用独立背景/文字色。点击打开对应详情，右下角“设置”重新配置。记录移除后显示重新选择，避免自动换成其他记录。

组件小布局突出标题、状态和天数；中布局增加起始日、昵称；大布局增加独立计算的下一次周年。桌面组件在跟随模式下支持照片与简化模板，独立配色模式使用纯色。旧版已有组件没有独立配置时，继续跟随置顶记录；配置后固定绑定所选记录。

## 日期与保存

默认开始当天为第 1 天，也可选择实际间隔；未来日期均按实际日历间隔倒计时。当天显示“就是今天”。累计天数与周年倒计时分别计算，周年当天倒计时为 0。

按手机当前时区的 LocalDate 计算，跨日、返回前台、日期或时区变化时刷新。2 月 29 日在非闰年的周年日为 2 月 28 日，闰年恢复 2 月 29 日。未来事件的下一纪念日期不会早于起始日。

记录、分类、配色和设置使用单个 AtomicFile JSON 快照；进程共享锁防止小组件读取与页面保存竞争。数据格式为 v3，可读取 v1/v2 本地数据和旧备份；已有记录默认未分类。保存成功后才更新界面。

照片复制到私有目录，应用 EXIF 方向并压缩为静态 JPEG，最长边至多 1800 像素，源图限制 30 MB。外部原图移除后不影响已导入的副本。透明和动画不保留；未引用的旧照片在一天宽限后于后续保存时清理。

## 备份恢复

设置中导出 ZIP，包含记录、分类、全部记录配色、主题/默认规则/动画设置和引用中的照片。恢复前确认、完整校验，再整体替换，不合并。兼容 v1/v2 ZIP；失效分类归入未分类。最多 500 条纪念日，解包总量上限 150 MB。

桌面实例的位置由桌面管理，实例绑定与独立配色保存在本机，不随 ZIP 转移。恢复记录时不会自动改绑现有组件；引用不存在时显示重新选择。新手机或重新安装后需重新添加和配置组件。

备份未加密，含个人信息，请保存在可信位置。卸载会清除私有数据；系统云备份和应用设备迁移关闭。升级安装同一签名 APK 会保留数据。
